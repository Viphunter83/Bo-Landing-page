# 📜 Tenant Implementation Log & Guide

Этот документ служит журналом изменений и руководством по внедрению мультиарендности (multi-tenancy) в проекте Bo Landing Page.

## 📅 Последние изменения (Сессия 1)

### 1. Инфраструктура и Безопасность
- **Firestore Rules**: Обновлены правила безопасности для изоляции данных. 
  - Все заказы (`orders`) и бронирования (`bookings`) теперь требуют `tenantId`.
  - Добавлена коллекция `site_settings/{tenantId}` для публичных настроек сайта.
  - Внедрена функция `isValidTenant` для валидации разрешенных ID (например, `bo_dubai`, `luna_hcmc`).
- **Migration Script**: Рефакторинг `scripts/migrate.ts`.
  - Теперь использует `dotenv` для загрузки ключей Firebase.
  - Автоматически внедряет `tenantId` во все документы.
  - Создает записи в `site_settings` на основе актуального конфига.
  - Поддерживает изолированные ID документов (например, `bo_dubai_pho-bo`).

### 2. Динамический брендинг (PWA)
- **Manifest**: Статический `manifest.json` заменен на динамический `app/manifest.ts`. 
  - Иконки, цвета и названия теперь подтягиваются из `tenantConfig` на основе `NEXT_PUBLIC_TENANT_ID`.

### 3. SEO и Метаданные
- **Layout & Sitemap**: Все канонические URL теперь используют `NEXT_PUBLIC_BASE_URL`.
- **Robots.txt**: Ссылка на sitemap теперь формируется динамически.

### 4. UI компоненты
- **Offer Page**: Страница акций (`app/offer/[code]`) полностью переведена на использование `tenantConfig`. Поддерживает динамические цвета (HSL) и мультиязычность.

## 📖 Как добавить новый ресторан (Тенент)

1. **Добавление конфига**: Откройте `app/lib/config/tenant.ts` и добавьте новый объект в `TENANT_CONFIGS`.
2. **Переменные окружения**: В Vercel установите:
   - `NEXT_PUBLIC_TENANT_ID`: уникальный ID (например, `luna_hcmc`).
   - `NEXT_PUBLIC_BASE_URL`: URL сайта (например, `https://luna-hcmc.com`).
   - `NEXT_PUBLIC_FIREBASE_*`: Ключи нового проекта Firebase.
3. **Миграция**: Запустите скрипт миграции (будет обновлен), чтобы заполнить Firestore начальными данными (меню, контент).
